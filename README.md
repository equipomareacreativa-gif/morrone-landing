# Landing Morrone Distribuciones

Sitio estático (un solo `index.html` + carpeta `assets/`). No necesita build.

## Publicar en Vercel
1. Subí esta carpeta a un repositorio de GitHub (por ejemplo `morrone-landing`).
2. En Vercel: Add New → Project → importá el repo.
3. Framework Preset: **Other**. Build Command y Output Directory: vacíos.
4. Deploy. Después, en Settings → Domains, sumá el dominio de Morrone.
